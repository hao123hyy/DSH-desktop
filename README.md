# DSH桌面版 —— DeepSeek Harness 桌面客户端

把 `dsh web` 的浏览器界面封装成一个 Windows 桌面应用：**双击即用，无需打开命令行，无需手动启动任何服务**。

## 特性

- **双击即用**：无控制台窗口，独立窗口内显示与命令行 `dsh web` 完全相同的 Web UI；
- **零安装依赖**：无需安装 Node.js，无需管理员权限；
- **数据互通**：会话、工作区、凭据、配置沿用你现有的 `%USERPROFILE%\.dsh`，与命令行用法完全互通；
- **在线更新**：启动后自动检查服务端组件更新，一键升级，失败自动回滚；
- **干净退出**：关闭窗口即结束服务进程树，不留后台孤儿进程；
- **网络友好**：默认走国内镜像源下载，直连失败自动转系统代理，国内网络环境开箱即用。

## 安装与使用

1. 在 [Releases](https://github.com/hao123hyy/DSH-desktop/releases) 下载最新版本：
   - **`dsh-desktop-<ver>-win-x64.zip`**（推荐）：解压后双击 `DSH桌面版.exe`；
   - `dsh-desktop-<ver>-portable.exe`：单文件便携版，双击直接运行。
2. **首次启动需要下载完整包**：应用会自动下载服务端组件（约 200MB）与 Node.js 运行时（约 90MB），窗口内显示进度；下载完成后即开即用。

## 工作原理（简要）

安装包只包含应用外壳（Electron 壳，约 86MB），不携带任何服务端代码与运行时——服务端组件与 Node.js 均由应用在首次运行时自动下载并校验（SHA-512），因此安装包干净、可审计，也便于分发。

## 常见问题

- **首次运行一直停留在「下载服务端组件」**：多为网络问题。可尝试在菜单「文件 → 下载源」切换下载源，或开启系统代理后重试。
- **没有 Node.js 也能跑**：应用会自动下载 Node.js 运行时；下载失败时回退使用系统中已安装的 Node。
- **日志**：菜单「帮助 → 打开服务日志」查看 `%APPDATA%\dsh-desktop\server.log`；启动异常排查看同目录 `crash.log`。
- **端口冲突**：每次启动自动探测空闲端口，不与手动启动的 `dsh web` 冲突。
